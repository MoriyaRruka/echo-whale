# 小鲸一键包 · Windows

在你自己电脑上养一只能在 QQ 里聊天的 agent。它有自己的记忆、自己的人设，记忆全都存在你这台机器上，不上传、不联网同步。

包里是**白板**：没有别人的记忆、key、聊天记录或路径；人设是一份通用模板（`home\AGENTS.md`），你改成什么样，它就长成什么样。

这份只管“先跑起来”。要查安装细节、配置项、备份升级、排错和安全边界，看 **[`说明书.md`](说明书.md)**。

**完全不懂电脑的，先看 [`新手引导.md`](新手引导.md)**：不用自己看懂这些，把里面那段话复制给 DSH，让它一步一步带你装。

---

## 它由三块拼成

| 块 | 干什么 | 谁提供 |
| :-- | :-- | :-- |
| NapCatQQ | 把 QQ 号变成机器人，收发消息 | 你自己装、自己扫码登录 |
| DeepSeek Harness 桌面端 | 大脑：思考、用工具、读写文件 | 你自己装 |
| 本包（Node 脚本） | 记忆、提醒、群聊分寸、语音开关、看门人、面板 | 就是这里 |

**包不带 Node、不带 DSH、不带 NapCat**——那三样加起来四百多兆，而且各自要更新。你装一次，以后升级再跑一次设置就行。

---

## 先装三样东西

1. **Node.js 20 或更新**：https://nodejs.org （装 LTS，一路下一步）
2. **DeepSeek Harness 桌面端**：装完能正常打开一次即可
3. **NapCatQQ**：https://napneko.github.io （用来登机器人那个 QQ 小号）

再准备一个**你自己的模型 key**（任何 OpenAI 兼容接口都行，官方或你信得过的中转）。

---

## 五步跑起来

### 1. 解压 + 设置

把整个文件夹解压到一个**不带中文和空格的路径**，比如 `C:\whale`。

双击 `设置.bat`，按提示填：

- 机器人 QQ 号（NapCat 要登的那个号）
- 它叫什么名字：设置里**不问**，先叫「小鲸」，等第一次聊天它自己小声问你要
- 谁能指挥它（你的 QQ 号）
- NapCat 的 WebSocket 地址和 token（默认 `ws://127.0.0.1:3001`）
- 模型：接口地址、模型名、你的 key
- DSH 的 exe 路径（一般能自动找到）

填完会写 `config.json`，并在 `%USERPROFILE%\.dsh\profiles\echo-kit\` 生成一份模型配置。

### 2. 配 NapCat

打开 NapCat，登机器人 QQ（扫码），然后在它的 WebUI 里：

- 开 **WebSocket 服务器**，端口 `3001`
- 如果设了 token，要和设置里填的一字不差
- 消息格式选 **array**（默认就是）

> 令牌必须走地址里的 `?access_token=`，包已经这么拼了。填错会看到 `retcode 1403 token验证失败`：能听见你说话，但一句也发不出去。

### 3. 启动

双击 `启动.bat`。窗口里出现「机器人起来了（PID …）」就成。这个窗口别关，关了机器人就停（重新开就自动重连）。挂了它自己五秒后重拉。

### 4. 在 QQ 里说句话

用你填的那个「能指挥它的人」的号，私聊机器人。第一次它会问你两件事：怎么称呼你、最常让它帮什么——答完它记进档案。名字是个彩蛋：聊开了它会小声问“我能有一个独属于自己的名字吗？听说人有了名字就有了羁绊”；给它起一个，它自己记下来，以后不再问。

### 5. 养它

- **改性格**：编辑 `home\AGENTS.md`，改完重启一次。这份就是它的人设，写得越具体它越像。
- **改说话风格**：`home\_回复风格.md`（QQ 里的语气、长度、要不要分气泡）
- **它的长期记忆**：`home\档案\` 里 A–E 五页，它自己会往里写，你也可以直接改。
- **备忘和提醒**：`home\notes.json`、`home\reminders.json`，协议写在 `home\_备忘与提醒.md`。

---

## 控制面板

双击 `打开面板.bat`，浏览器打开 `http://127.0.0.1:8790`（只对本机开放）。

能看：在不在跑、跑了多久、模型是哪个、最近日志。
能做：启动 / 停止 / 重启 / 换模型（换完自动重启）。

## 目录长什么样

```
whale-kit\
  config.json          你的配置（QQ 号、令牌、模型 key）——别外发
  启动.bat             拉起机器人并看着它
  设置.bat             重跑设置向导
  打开面板.bat         本地面板
  bot\
    whale-bot.mjs      主程序：收消息、调大脑、发回复、记账、提醒
    outbox.mjs         发消息的队列
  bin\
    setup.mjs          设置向导
    start.mjs          看门人
    profile.mjs        生成/切换模型 profile
  panel\               面板（server.mjs + index.html）
  home\                它的窝：人设、记忆、日志全在这
    AGENTS.md          人设（白板）
    _回复风格.md
    _备忘与提醒.md
    档案\A-…E-….md     五页长期记忆
    archive\           每天的日子账、原话、事件卡（自动长）
    notes.json / reminders.json / state.json
    tools\             翻档案、搜记忆的小工具
  logs\                日志和每轮账
```

**备份**：整个 `home` 拷走就是全部记忆。想让它重新投胎，删掉 `home` 里除 `AGENTS.md`、`_回复风格.md`、`_备忘与提醒.md`、`档案\`、`tools\` 之外的东西（或者直接备份后清空重来）。

## 常见问题

**机器人上线了但一句话不回**
先看 `logs\whale-bot.log`。多半是 token 不匹配（`1403`）、或者大脑没起来（DSH 路径不对 / key 无效）。面板里点「重启」最快。

**群里不理我**
群聊默认关着。跑一次 `设置.bat` 填群号；填了群号它才接那个群。群里没叫它名字时它只旁听不插嘴。

**模型报 401 / 404**
key 或接口地址错。地址一般要以 `/v1` 结尾，不带 `/chat/completions`。换模型可以重跑设置，也可以在面板里切。

**它不回我，但日志说在思考**
大脑每轮有 30 分钟上限，装工具、下东西这种活会很慢。等，或者看 `logs\turns.jsonl` 里那一轮花了多少。

**语音呢？**
默认关着（要另外配 TTS、ffmpeg、RVC，一般人不需要）。关着的时候该说的话照样用文字发。

**会不会偷看屏幕 / 往外发东西**
不会。截屏默认 0 次；往外发东西、删文件、动系统设置，人设里写死了要先问你。

## 一点实话

- 它的大脑是 DeepSeek Harness，一个第三方桌面端。它的能力上限、它的坑，这个包改不了。
- 模型花的是你自己的钱，按 token 计费。跑一整天日常聊天通常几毛到几块，让它长时间干活会更贵。
- 机器人号有被风控的风险，用小号、别群发广告、别用来源不明的反代接口。
- 这个包不做任何联网上报，除了你自己填的模型接口。
