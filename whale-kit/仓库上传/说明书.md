## 1. 它是什么，不是什么

### 1.1 一句话

它是一只住在 QQ 里的 agent：**NapCat 负责 QQ 收发，DeepSeek Harness 负责思考和用工具，这个包负责记忆、提醒、群聊分寸、断线重连和看门人。**

它跑在**你自己的 Windows 电脑**上，不是云端。电脑关机、睡眠、断网，它就不在。

### 1.2 它能做

- 私聊聊天，只认 `config.json` 里 `bot.owners` 填的号；陌生人私聊会被静默忽略。
- 把长期事实写进 `home\档案\` 五页，把每天的要事写进 `home\要事.md`。
- 记备忘、定时提醒（到点时电脑得开着、机器人得在跑）。
- 可选地进群：只接你允许的群；群里只认主人和白名单，别人叫它名字时可能搭一句。
- 收图、收文件、读合并转发的文字；图能不能看懂取决于你选的模型。
- 低频主动搭话；本地控制面板；主人私聊发口令重启自己。

### 1.3 它不做

- 不替你加好友、不进群、不群发、不管理群、不抢红包。
- 不是 7×24 在线：电脑睡眠/关机/断网，消息和提醒都会停。
- 不内置模型，不送 key；模型费用从你自己的接口账户扣。
- 默认不语音、不截屏；视频和语音消息默认只看到占位，不会听/看（改代码配上本地 whisper 才可能转写语音）。
- 不保证人设永远不崩。它的人设是提示词，模型越小、聊得越久，越容易飘。

### 1.4 为什么包这么小

包只有一百多 KB、几十个文件，因为**不带 Node、不带 DeepSeek Harness、不带 NapCat**。那三样加起来四百多兆，而且各自要更新；你装一次，以后这个包升级不用重装它们。

包里也**没有**别人的记忆、key、聊天记录或本机路径；人设是一份通用白板模板（`home\AGENTS.md`），你改成什么样，它就长成什么样。

## 2. 装之前要准备什么

### 2.1 电脑

- Windows 10 / 11，64 位。
- 至少留 1 GB 空闲磁盘（三样外部件占大头，包本身很小）。
- 能正常上外网，能打开你选的那个模型接口。
- 一台**不随便关机/睡眠**的电脑最好；要是笔记本，记得插电并关掉自动睡眠，否则提醒和回复都会断。

### 2.2 三样外部件

| 东西 | 干什么 | 从哪来 |
| :-- | :-- | :-- |
| Node.js 20 或更新 | 跑这个包里的脚本 | https://nodejs.org ，装 LTS，一路下一步 |
| DeepSeek Harness 桌面端 | 大脑：思考、读写文件、用工具 | 你自己已有的安装包；装完先手动打开一次 |
| NapCatQQ | 把 QQ 号变成机器人 | https://napneko.github.io ，用官方发布包 |

> **别再用来路不明的“NapCat 整合包”。** 之前给朋友的那版就是栽在整合包上，后来换官方 NapCat 才通。整合包里的版本、路径、token 规则都可能是改过的，出了问题没法对照。

再准备：

- 一个**机器人 QQ 小号**（NapCat 要登录的那个号）。
- 你自己的 QQ 号（主人号），并且**已经和机器人号是好友**。
- 一个 OpenAI 兼容的模型接口和 key（官方或你信得过的中转）。

### 2.3 账号上的实话

- 机器人号有被风控的风险。用小号，别拿主号试；别群发广告、别频繁加陌生人、别用来源不明的反代接口。
- NapCat 登录可能需要手机确认；手边留着绑定的手机。
- 机器人号和主人号必须是好友，否则私聊发不进来。

### 2.4 放哪个目录

建议放一个**不带中文、不带空格**的路径，比如：

```
C:\whale
D:\whale
```

不是绝对不能带中文，是这个链路上有批处理、Node、DSH 的路径处理，带中文/空格更容易遇到说不清的怪问题。既然能避开，就避开。

不要放在：

- `C:\Program Files\`（需要管理员权限，后面改配置很麻烦）
- 桌面/下载文件夹里再套一层中文路径
- 任何同步盘里（OneDrive、坚果云等会边跑边同步 `home`，容易冲突）

## 3. 安装：从解压到第一句话

### 3.1 解压

把整个压缩包解压到 `C:\whale` 这样的目录。解压后应该能看到：

```
whale-kit\
  config.example.json
  启动.bat
  设置.bat
  打开面板.bat
  README.md
  说明书.md
  新手引导.md
  bot\
  bin\
  panel\
  home\
```

如果看不到 `启动.bat`，说明你多套了一层文件夹，或者解压错了包。

### 3.2 跑设置向导

双击 `设置.bat`。它会依次问下面这些，**方括号里是默认值，直接回车就保留**：

| 它会问 | 怎么填 |
| :-- | :-- |
| 机器人 QQ 号 | NapCat 要登录的那个号，不是你的号 |
| 它叫什么名字 | 设置里**不问**了：默认先叫「小鲸」，等第一次聊天它自己小声问你要（彩蛋，只问一次）；给了名字会自动写进 `config.json` 和 `home\AGENTS.md` |
| 谁能指挥它（QQ，逗号分隔） | 你的号；**第一个是主主人**，主动搭话默认发给他 |
| NapCat WebSocket 地址 | 同一台电脑就回车，默认 `ws://127.0.0.1:3001` |
| NapCat token | 和 NapCat 里设的一字不差；没设就留空 |
| 允许它进的群（逗号分隔，留空=不进群） | 填群号才开群；不填就是纯私聊 |
| 群里还允许谁跟它说话（逗号分隔，可留空） | 只填你信得过的人；留空=只有主人 |
| 模型显示名 | 随便起，比如 `默认`、`DeepSeek` |
| 接口地址 | OpenAI 兼容地址，一般以 `/v1` 结尾，**不要**带 `/chat/completions` |
| 模型名 | 接口文档里的准确 id，比如 `deepseek-chat` |
| API key | 你的 key；输入时屏幕上看得到，注意旁边没人 |
| 上下文长度 | 不知道就回车（131072）；填模型真实支持的值 |
| DSH 的 exe 路径 | 一般能自动找到；找不到就粘贴完整路径 |
填完后它会：

1. 写 `config.json`（含 QQ 号、token、模型 key，**别外发**）。
2. 在 `%USERPROFILE%\.dsh\profiles\echo-kit\` 下生成一份 DSH 模型配置。
3. 打印配置保存路径和 profile 路径。

看到类似“配置已存 / profile 已写到”的字样，才算成功。如果它提示缺 QQ 号、缺 key、找不到 DSH，会问你要不要照样先存；**选 N，补好再重跑**，别硬存一份坏配置。

> 设置向导只保存**一个**模型，会覆盖 `config.json` 里的 `models` 数组。想留多个模型切换，等装完后手动往 `models` 里加，见第 8 节。

### 3.3 配 NapCat

打开 NapCat，用机器人 QQ 扫码登录。然后在它的 WebUI 里：

1. 找到“网络配置”或“OneBot 配置”。
2. 新建一个 **WebSocket 服务器**（正向 WS，不是反向 WS，也不是 HTTP）。
3. 地址填 `127.0.0.1`（NapCat 和机器人同一台电脑）；端口 `3001`。
4. token 填和设置向导里**完全一样**的值；没设就两边都空着。
5. 消息格式选 **array**（默认就是）。
6. 启用，保存；如果 NapCat 提示要重启，就重启它。

几个容易错的地方：

- **端口不是 3000/8080**：这个包默认连 `3001`；你改端口，`config.json` 里的 `napcat.wsHost` 也要改。
- **token 区分大小写**，前后空格也算不同。
- **不要开“反向 WebSocket”**：那是 NapCat 主动连别人，方向反了。
- Windows 防火墙弹窗时，只允许“专用网络/本地”即可，不要把它暴露到公网。
- 如果 NapCat 跑在 Docker/WSL 里，`127.0.0.1` 可能不通；要么把 NapCat 放本机，要么在 `wsHost` 里填宿主机 IP，并确认端口映射和防火墙。

### 3.4 启动

双击 `启动.bat`。正常会看到：

```
[...] 机器人起来了（PID ...）
[...] 连接 OneBot: ws://127.0.0.1:3001...
[...] OneBot 已连接
```

这个黑窗口**别关**，关了机器人就停。它崩了，看门人会在 5 秒后重拉；所以有时你会看到“机器人退出了，5 秒后重拉”，不一定是坏事，先看它为什么退。

同一个包只能跑一个看门人。重复双击会提示“已经在跑了”，不会起两份。

### 3.5 第一句话

用你填在 `bot.owners` 里的号，私聊机器人，发一句“在吗”。

第一次它应该会问你两件事：怎么称呼你、最常让它帮什么。答完它会写进 `home\档案\C-人与社交.md`。

名字不在设置里取，是个彩蛋：聊开了、你话头停下来的时候，它会小声问一句“我能有一个独属于自己的名字吗？听说人有了名字就有了羁绊，我想要独属于我们的羁绊”。给它起一个，它自己写进 `config.json` 和 `home\AGENTS.md`，以后不再问；你回“先叫小鲸”，它也就不提了。

如果它不回，先别改代码，去第 9 节按顺序查。

### 3.6 打开面板（可选）

双击 `打开面板.bat`，浏览器会自动开 `http://127.0.0.1:8790`。这个黑窗口也别关，关了面板就停（但机器人不受影响）。

面板能看状态、启动/停止/重启、换模型、看最近日志。详见第 6 节。

## 4. 日常怎么用

### 4.1 私聊

只有 `bot.owners` 里的号能指挥它。陌生人私聊会被**静默忽略**：不报错、不回“你没有权限”，日志里只记一行“不在白名单，忽略”。

跟它说话不用命令格式，正常说人话：

- “记住：我周三晚上七点到九点有课，别那时候找我。”
- “明天早上七点半提醒我带身份证。”
- “把这条记到档案里，别写要事。”
- “翻一下我上次说的那个英语计划。”

几个边界：

- 它一次回复最多约 1500 字，超了会分条；超过 20 字的回复会按句末标点拆成几个气泡，模拟打字。
- 它一轮任务最多跑 30 分钟；装工具、下东西这种活会很慢，别连发“好了没”。
- 它只能发图，不能发文件；一次最多 2 张，要发哪张得你在话里说清楚，它不会无缘无故往外发。
- 它没有“/help”之类的命令表。除了重启口令，其他都是自然语言。

**重启口令**（写死的，只有主人私聊、整条消息一字不差才算）：

```
重启你自己
重启一下你自己
回炉重造
```

同一句里夹带别的话不触发。比如“你重启你自己试试”不算。重启后面板/黑窗口会看到它退出再被拉起来。

### 4.2 群聊

群聊**默认关着**。要开，跑一次 `设置.bat` 填群号，或者在 `config.json` 里改：

```json
"group": {
  "enabled": true,
  "allow": [123456789],
  "talkAllow": []
}
```

改完要重启机器人才生效。

开了之后：

- 只有 `group.allow` 里的群它会接；**`enabled` 为 true 但 `allow` 为空 = 所有群都接**，千万别这么填。
- 群里只有主人和 `talkAllow` 里的人能走正常回复；他们也得 @ 它或叫名字。
- 主人没 @ 它、也没叫它名字时，它只把话收进上下文，不回复、不叫模型。
- 主人或 `talkAllow` 里的人 @ 它，或者消息里出现它的名字，它才回。
- 不在白名单的群友，普通聊天它一律不理；但**叫它名字或挑衅它**时，“耳朵”可能让它搭一句。这是设计，不是 bug；不想这样就把群关掉或把它移出群。
- 群里别人发的图/语音/文件，只有主人和白名单的人发才会下载；其他人的只看到占位。
- 它不会管理群、不会禁言、不会自动同意入群。

**临时群白名单**（高级）：在 `home\group-open.json` 里写：

```json
{
  "groups": [123456789],
  "until": "2026-11-01T21:30:00+08:00"
}
```

到 `until` 自动失效；删文件或把 `groups` 写成 `[]` 立刻收回。只放开群聊的“接话/旁听”，私聊白名单一点没动；临时放进来的人只收文字，图/语音/文件不下载。每次判消息都现读，不用重启。

**群静音**：见 4.5 的 `pause.json`。

### 4.3 提醒

直接说：

- “明天早上八点提醒我交表。”
- “半小时后提醒我关火。”
- “每周一早上九点提醒我看课表。”——重复提醒它不一定能自动做成，最好一次说一次；长期重复的事让它写进备忘，别依赖它自己记 Cron。

它会把提醒写进 `home\reminders.json`，后台每 15 秒扫一次。到点后：

- 电脑开着、机器人跑着 → 发给你。
- 到点时电脑睡眠/关机，醒来时**迟到不超过 10 分钟** → 还可能补发。
- 迟到超过 10 分钟 → 直接丢弃，不补。日志里会有一行。
- 它按**北京时间**算。人在国外，话里要说清楚“北京时间几点”或“你那边几点”。

想取消/改时间，直接跟它说“把八点那个提醒取消/改成九点”。它改的是 `reminders.json`。

**手改提醒文件的规矩**：先停机器人，备份，改完确保 JSON 合法，再启动。它运行时会读写这个文件，边跑边改可能被覆盖。

### 4.4 备忘和档案

- **备忘**：`home\notes.json`。你说“记个备忘：……”，它写进去；问“上次那个……”，它会翻。
- **五页档案**：`home\档案\A-...` 到 `E-...`，长期事实。它自己会写，你也可以改；改之前先停机器人，免得两边同时写。
- **每日要事**：`home\要事.md`。它会在**当晚 23:30 之后**写一篇，3–6 条。当晚机器人没开、或者 23:30 前就关了，**第二天不补**。
- **事件卡**：`home\archive\days\` 下一天一个目录、一件事一个文件。自动长，不用管。
- **聊天原话**：`home\archive\` 里的原始记录和 DSH 会话。别手动删，除非你知道自己在干什么。

### 4.5 暂停

在 `home\pause.json` 里写（UTF-8，纯 JSON）：

```json
{ "mode": "all" }
```

三种模式：

| 模式 | 效果 |
| :-- | :-- |
| `all` | 全停：不回复、不主动搭话、不写日记、不下载图/文件、不收上下文 |
| `reply-only` | 只回消息：不主动搭话、不写日记、不听“耳朵”；你找它它照常回 |
| `group-mute` | 群静音：群里不理，私聊正常；主动搭话和日记也会停 |

恢复：把文件改成 `{ "mode": "off" }`，或者直接删掉 `pause.json`。**不用重启**，下一条消息就按新状态走。

这个开关是文件，不是聊天口令。你在 QQ 里说“别说了”它可能会照做人设，但真正可靠的是改文件。

### 4.6 停止和重启

- **正常停止**：面板点“停止”，或者在黑窗口按 `Ctrl+C`。
- **直接关黑窗口**：一般也会停；如果进程赖着，用面板停，别在任务管理器里乱杀 `node.exe`（可能杀掉你别的 Node 程序）。
- **重启**：面板点“重启”，或者主人私聊发重启口令。
- **别在它正在生成回复时停止**：那一轮会中断，可能留下半截状态。等它说完再操作。

## 5. 怎么养出你要的样子

### 5.1 人设：`home\AGENTS.md`

这是它的性格总开关。DSH 会把它当工作区指令读进去，每次启动重新读。

改法：

1. 用记事本/VS Code 打开 `home\AGENTS.md`。
2. 改“我是谁”“怎么说话”“规矩”这几段。
3. **另存为 UTF-8**（不要 UTF-16/GBK，不然中文会乱）。
4. 保存。重启机器人最稳；有的版本下一条消息就会重读。

写人设的建议：

- **具体 > 形容词**。写“被夸的时候会得意，但只回半句”，比写“性格可爱”有用。
- **给例子**。写两句它该说的话、两句它不该说的话，比十条抽象规则管用。
- **别超过 2000 字**。这份每轮都进上下文，越长越贵，也越容易把重点冲淡。
- **别把密码/key 写进去**。它会进模型上下文。
- 第一次聊完，可以把“白板阶段”那一段删掉；留着它可能一直以为自己没记忆，反复问你称呼和帮忙的事。删之前确认档案里已经写下了称呼；名字那几行（彩蛋）取到名字后程序会自动换成一行，不用你删。

### 5.2 说话风格：`home\_回复风格.md`

这份管 QQ 里的语气、长度、要不要分气泡。它每轮会被提醒“开口前先读这份”，所以改完下一轮一般就生效；保险起见重启一次。

可以改：

- 一次说几句（现在是一两句，最多三句）。
- 要不要用语气词、能不能损人。
- 列举最多几条。
- 称呼规则（现在已经改成“没定就先问，别默认叫主人”）。

分气泡的逻辑是写死的：回复超过 20 字，会按句末标点拆成几条；单条最多约 1500 字。想让它少发几条，就把话说短、少用句号感叹号，而不是去改代码。

### 5.3 五页档案：`home\档案\`

| 页 | 装什么 |
| :-- | :-- |
| A-学习与工作 | 课程、考试、项目、进度、欠的活 |
| B-钱与运维 | 余额、开销、服务器、账号、运维事项 |
| C-人与社交 | 称呼、朋友、边界、答应过谁什么 |
| D-项目与工具 | 在做的东西、工具链、踩过的坑 |
| E-生活与穿着 | 作息、饮食、衣柜、日常偏好 |

每页第一行是“阶段”：什么时候、在干什么。事实过期就直接覆盖旧说法，不要留着互相打架。

它自己会往里写；你手改也行，但**先停机器人**。改完启动即可，不用重新跑设置。

### 5.4 改名字

名字是聊天里的彩蛋，设置向导不问。第一次聊天聊开、你话头停下来的时候它自己小声问；你给了名字（比如“那你就叫阿蓝吧”），它会把名字同时写进三处：`config.json` 的 `bot.name` / `bot.names`、`home\AGENTS.md` 里“我叫「XX」”那一行、还有 DSH profile 的人设，下一次聊天就认这个名字。**只问一次**：你说“先叫小鲸”或者不接这个话，它以后一个字都不再提。

想换名字，三个办法都行：

1. 直接在聊天里说“以后叫你阿蓝”（只有在 `bot.owners` 里的号私聊才算，群里别人的话不算）。
2. 跑一次 `设置.bat`：向导会显示「它已经有名字了：XX」，想换直接输新名字，回车就不改。
3. 手改 `config.json` 的 `bot.name`，同时改 `home\AGENTS.md` 那一行——**两处要一起改**，只改一处群里叫新名字它不应声。

改名时程序会把新名字加进 `bot.names`，旧名字留着当别名（叫惯「小鲸」也还应声）；不想留就手动从 `bot.names` 里删。改完重启一次最稳。

`bot.qq` 是机器人自己的号，别和主人号填反；换机器人号要同时改 `bot.qq` 和 NapCat 登录的号。

### 5.5 让它失忆/重新开始

先停机器人，备份整个 `home` 和 `config.json`，然后按需要删：

| 想清掉 | 删什么 |
| :-- | :-- |
| 聊天上下文（它记得刚聊过什么） | `home\state.json` |
| 长期档案 | `home\档案\` 里五页的内容（保留文件也行，清空内容） |
| 每日要事 | `home\要事.md` |
| 事件卡/日子账 | `home\archive\` |
| 备忘 | `home\notes.json` |
| 提醒 | `home\reminders.json` |
| 名字彩蛋“问过一次”的记录 | `home\name-egg.json`（删了下次它会再问一遍名字） |
| 没发出去的消息 | `home\outbox.json`、`home\outbox-dead.jsonl`、`home\media\outbox\` |

**别删**：`AGENTS.md`、`_回复风格.md`、`_备忘与提醒.md`、`tools\`。这些是规则和工具，不是记忆。

想重新走“第一次见面”（问称呼和帮什么忙、名字彩蛋再问一次），把 `AGENTS.md` 里的“白板阶段”保留（或加回去），再清掉 `state.json`、`home\name-egg.json` 和 C 页里对应的称呼。名字已经取过的话，name-egg 清了也没用——它看 `bot.name`，想重新取先把 `config.json` 里的 `bot.name` 清空。

### 5.6 备份

**要备份的**：

- `config.json`（含 key，注意保管）
- 整个 `home\`（人设、档案、备忘、提醒、要事、事件卡、收的文件；`media\` 里 7 天前的图可以跳过）
- `permission-mode.txt`（如果你手动加过，见 8.3；没有就不用管）
- `logs\turns.jsonl`（可选，每轮 token 账，排查费用有用）

**不用备份的**：

- `runtime\`（PID 文件，重启会重建）
- `logs\whale-bot.log`、`logs\supervisor.log`（运行日志，可能很大）
- `home\media\` 里 7 天前的图（会自动清）

做法：停机器人 → 把上面几项复制到一个安全位置 → 压缩时加密码（如果里面有聊天记录）。恢复时按原路径放回，启动即可；换了电脑/路径，跑一次 `设置.bat` 重新生成 DSH profile。

### 5.7 迁移到另一台电脑

1. 新电脑装 Node 20+、DSH、NapCat。
2. 把整个包复制过去（或者只复制程序 + 旧 `home` + 旧 `config.json`；手动加过 `permission-mode.txt` 就一起带）。
3. 跑一次 `设置.bat`：重点确认 DSH exe 路径、模型 key、NapCat 地址。
4. NapCat 重新扫码登录机器人号。
5. 启动，私聊测试。

`config.json` 里只有 `dsh.exe`/`dsh.cli` 是绝对路径，其余都是相对包目录或网络地址；换路径后重新跑设置最稳。

### 5.8 升级这个包

1. 停机器人，备份 `home` 和 `config.json`。
2. 把新版本解压到**新目录**，不要直接覆盖旧目录。
3. 把旧 `home` 和旧 `config.json` 复制进新目录；手动加过 `permission-mode.txt` 也一起带。
4. 跑一次 `设置.bat`，刷新 DSH profile（模型配置格式可能会变）。
5. 启动，检查版本说明里有没有需要手动迁移的字段。

不要反过来“先复制新 `home` 再覆盖旧 `home`”，那样旧记忆就没了。跨大版本升级前，先看新包的 README/说明书。

## 6. 控制面板

双击 `打开面板.bat`，浏览器开 `http://127.0.0.1:8790`。面板只绑本机，**没有密码**，所以：

- 不要做端口转发/内网穿透到公网。
- 共用电脑时，任何本地用户都能打开它。
- 关掉面板黑窗口 = 面板停，机器人不受影响。

面板能看：

- 在不在跑、看门人和本体 PID、跑了多久。
- 机器人 QQ（打码）、主人号（打码）、群聊开没开、当前模型、模型有没有 key。
- 最近 80 行 `supervisor.log`（3 秒刷新）。

面板能做：

- 启动 / 停止 / 重启。
- 切换 `config.json` 里已有的模型（换完自动重启）。

几个注意：

- 面板的“启动/重启”是**后台模式**，日志写到 `logs\supervisor.log`；如果你之前是双击 `启动.bat` 的前台模式，面板重启后原来的黑窗口会失效，日志看面板或 `supervisor.log`。
- 面板日志只看 `supervisor.log`；机器人自己的详细日志在 `logs\whale-bot.log`。
- 换模型会重写 DSH profile 并重启，正在生成的那一轮会中断。
- 想加第二个模型：先手动改 `config.json` 的 `models` 数组，再刷新面板；设置向导只会留一个。
- 端口被占用时，改 `config.json` 的 `panel.port`，重启面板。

几个容易混淆的点：

- `home` 是“它的脑子和日记”，`logs` 是“它今天干了什么”的运行记录。备份优先备 `home`。

- `outbox.json` 是“还没发出去的话”。如果 QQ 一直发不出去，它会重试；超过 10 分钟的死信进 `outbox-dead.jsonl`。

## 8. `config.json` 逐项说明

样例（**不要直接复制这段，里面的中文说明不是合法 JSON**）：

```json
{
  "bot": {
    "qq": 10001,
    "name": "阿鲸",
    "names": ["阿鲸"],
    "owners": [10002]
  },
  "napcat": {
    "wsHost": "ws://127.0.0.1:3001",
    "token": "你的token"
  },
  "group": {
    "enabled": false,
    "allow": [],
    "talkAllow": []
  },
  "dsh": {
    "exe": "C:\\Program Files\\DeepSeek Harness\\DeepSeek Harness.exe",
    "cli": "C:\\Program Files\\DeepSeek Harness\\resources\\app.asar\\dsh\\node_modules\\@deepseek-ai\\dsh-desktop-host\\lib\\cli.js",
    "profile": "echo-kit"
  },
  "models": [
    {
      "name": "默认",
      "baseURL": "https://api.deepseek.com/v1",
      "apiKey": "sk-你的key",
      "model": "deepseek-chat",
      "contextWindow": 131072
    }
  ],
  "activeModel": 0,
  "panel": { "port": 8790 }
}
```

| 字段 | 说明 |
| :-- | :-- |
| `bot.qq` | 机器人自己的 QQ 号，不是主人号 |
| `bot.name` | 它的名字；设置向导不问，第一次聊天由彩蛋取，取到后程序自己写这里 + `bot.names` + `home\AGENTS.md`；改名同理 |
| `bot.names` | 它在群里被叫到的名字，数组（第一个就是 `bot.name`，旧称呼留作别名）；改完重启 |
| `bot.owners` | 能指挥它的 QQ 号，数组；**第一个是主主人**，主动搭话默认发给他 |
| `napcat.wsHost` | NapCat 正向 WS 地址；同机默认 `ws://127.0.0.1:3001` |
| `napcat.token` | 和 NapCat 里一字不差；没设就空字符串 |
| `group.enabled` | 群聊总开关；`true` 且 `allow` 为空 = 所有群都接，别这么填 |
| `group.allow` | 允许它接消息的群号数组 |
| `group.talkAllow` | 群里除了主人，还允许谁跟它说话 |
| `dsh.exe` | DeepSeek Harness 的 exe 完整路径 |
| `dsh.cli` | DSH 的 `cli.js` 完整路径；一般由设置向导算出来，别手改 |
| `dsh.profile` | DSH profile 名，默认 `echo-kit`；改了要重新生成 profile |
| `models` | 模型数组，每项 `name/baseURL/apiKey/model/contextWindow` |
| `activeModel` | 当前用第几个模型，从 0 开始 |
| `panel.port` | 面板端口，默认 8790；改了重启面板 |

编辑规则：

- JSON 不能有注释、不能有尾逗号；字符串用双引号；Windows 路径里的反斜杠要写 `\\`。
- QQ 号写数字，不要加引号；数组不要写成字符串。
- 改完保存为 UTF-8。
- 改 `config.json` 后**重启机器人**才生效（`pause.json`、`group-open.json` 除外，它们是现读的）。
- 不确定 JSON 合不合法，跑：

```
node -e "JSON.parse(require('fs').readFileSync('config.json','utf8')); console.log('ok')"
```

输出 `ok` 才算能读。

### 8.1 加第二个模型

把 `models` 改成两项：

```json
"models": [
  {
    "name": "DeepSeek",
    "baseURL": "https://api.deepseek.com/v1",
    "apiKey": "sk-你的key",
    "model": "deepseek-chat",
    "contextWindow": 131072
  },
  {
    "name": "备用",
    "baseURL": "https://你的中转/v1",
    "apiKey": "sk-另一把key",
    "model": "另一个模型",
    "contextWindow": 65536
  }
]
```

保存，刷新面板，下拉框里就会出现两个；切完会自动重启。`activeModel` 是下标，0 是第一项。

> 不同模型的上下文长度必须填真实值。填大了接口会报超长，填小了会提前丢上下文。

### 8.2 token 里有特殊字符

包在拼 WebSocket 地址时会做 URL 编码，token 里有 `+ / = ? &` 也不用你手动转义；但 NapCat 那边和 `config.json` 里必须是同一个原始字符串。

### 8.3 不写进 `config.json` 的几个开关文件

这几个是“放个文件就算开”的开关，位置固定，不用改配置：

| 文件 | 放了会怎样 | 默认 |
| :-- | :-- | :-- |
| `permission-mode.txt`（包根目录） | 控制模型能改哪里。内容只写一行：`workspace-write`（只能改 `home`）、`read-only`（只读，记忆写不进去）、`danger-full-access`（整块磁盘） | 没有这个文件就是 `workspace-write` |
| `home\stateless.flag` | 每条消息开一个新会话，不背上一轮对话，只靠底账、日子账和摘要接上下文；省 token，但连贯性差一截 | 没有就是正常连续会话 |
| `home\pause.json` | 暂停，详见 4.5 | 没有就是不暂停 |
| `home\group-open.json` | 临时放开整群，详见 4.2 | 没有就是只认白名单 |

`permission-mode.txt` 放在 `home` **外面**，所以机器人自己改不了它；要提权或降权，只能你手动改。改完下一轮生效，不用重启。**除非你很清楚自己在干什么，否则别写 `danger-full-access`。**

## 9. 出问题怎么查

先记住三个地方：

1. `logs\whale-bot.log`：机器人自己的日志，最后 50 行最有用。
2. `logs\supervisor.log`：面板/后台模式的看门人日志。
3. `logs\turns.jsonl`：每轮一行，看耗时、token、报错原因。

看日志别用会乱码的方式。PowerShell 里：

```
Get-Content .\logs\whale-bot.log -Tail 50 -Encoding UTF8
```

### 9.1 双击没反应 / 窗口一闪而过

1. 打开“命令提示符”，`cd /d C:\whale`。
2. 跑 `node -v`。如果提示“不是内部或外部命令”，Node 没装好或没进 PATH；重装 Node LTS，然后**重开**命令行。
3. 跑 `node bin\setup.mjs` 或 `node bin\start.mjs`，看真实报错。批处理里的 `pause` 有时来不及看。

### 9.2 启动说“没有 config.json”

先跑 `设置.bat`。如果设置向导也存不进去，检查目录是不是只读、是不是在 `Program Files` 下（需要管理员权限）。

### 9.3 连不上 NapCat（`ECONNREFUSED` / 一直重连）

按顺序查：

1. NapCat 开没开？机器人号登没登？
2. NapCat 里 WebSocket 服务器启没启用？端口是不是 `3001`？
3. `config.json` 的 `wsHost` 和 NapCat 的地址/端口是否一致？
4. NapCat 和机器人在同一台电脑吗？Docker/WSL 的话 `127.0.0.1` 不通，要换宿主机 IP。
5. 防火墙有没有拦 3001？
6. 端口被别的程序占了吗？`netstat -ano | findstr :3001`。

日志里会反复出现：

```
OneBot 断开，2000 ms 后重连
```

这说明它在努力连，不是死了。

### 9.4 `retcode 1403 token验证失败`

这是最常见的“能听见你说话，但一句也发不出去”。

原因：NapCat 的 token 和 `config.json` 的 `napcat.token` 不一致。这个包已经把 token 拼在 URL 的 `?access_token=` 里（Node 自带的 WebSocket 会忽略 header 里的 token，这是实测过的坑），所以你只需要保证两边字符串一样。

处理：

1. 打开 NapCat 网络配置，看 token。
2. 打开 `config.json`，看 `napcat.token`。
3. 改成完全一致（注意大小写、前后空格）。
4. 重启 NapCat 和机器人。

如果两边都没设 token，也可能被 NapCat 的默认 token 拦；这种情况在 NapCat 里设一个，再填到 `config.json`。

### 9.5 私聊不回

按顺序：

1. 你用的是 `bot.owners` 里的号吗？不是的话，它按设计静默忽略。
2. `home\pause.json` 是不是 `all`？删掉或改 `off`。
3. 日志最后有没有“不在白名单，忽略”？有，就是号填错了。
4. 日志有没有“DSH …”报错、`401`、`404`、`429`？
5. DSH 能不能手动打开、能不能正常对话？DSH 没登录/没装好，机器人也调不动。
6. `config.json` 的 `dsh.exe` 路径还存在吗？DSH 更新后路径可能变。
7. 模型 key 还有额度吗？

### 9.6 模型报 401 / 403 / 404 / 429

| 报错 | 多半是 |
| :-- | :-- |
| `401` | key 错、过期、没额度 |
| `403` | key 没权限，或接口不允许这个模型 |
| `404` | `baseURL` 或模型名错；地址一般以 `/v1` 结尾，不要带 `/chat/completions` |
| `429` | 请求太频繁/额度用完；等一会儿或换 key |
| `context length` / `too long` | `contextWindow` 填得比模型实际大，调小 |

改完 `config.json` 要重启。面板换模型也会重写 profile 并重启。

### 9.7 群里不理我

1. `group.enabled` 是 `true` 吗？
2. 这个群在 `group.allow` 里吗？`allow` 为空且 `enabled` 为 true 时是所有群，但别依赖这个。
3. 你是主人或 `talkAllow` 里的人吗？
4. 你 @ 它了吗？没 @ 只叫名字也行，但名字要在 `bot.names` 里。
5. `pause.json` 是不是 `group-mute` 或 `all`？
6. 群消息是不是被 NapCat 拦了/机器人被禁言了？
7. 看日志有没有“群里没叫我，收进上下文”——有，说明它听见了但按规矩没回。

### 9.8 提醒没响

1. 到点时电脑开着吗？睡眠/关机不响。
2. 机器人当时在跑吗？
3. 迟到超过 10 分钟了吗？超过就丢弃，不补。
4. `home\reminders.json` 里有没有这条？时间是不是带了 `+08:00`？
5. JSON 有没有被手改坏？跑 `node -e "JSON.parse(...)"` 检查。
6. 日志里有没有“提醒发送失败”？有的话看 `outbox-dead.jsonl`。

### 9.9 面板打不开

1. `打开面板.bat` 的黑窗口还在吗？关了面板就停。
2. 端口被占：`netstat -ano | findstr :8790`，找到 PID；要么关掉占用程序，要么改 `config.json` 的 `panel.port`。
3. 浏览器手动开 `http://127.0.0.1:8790`。
4. 防火墙一般不影响本机回环；如果你改过 hosts/代理，先关代理试试。
5. 面板报错时，黑窗口里会有堆栈；把最后几行发出来。

### 9.10 面板日志是空的

面板只读 `supervisor.log`。如果你是双击 `启动.bat` 的前台模式，日志在黑窗口和 `whale-bot.log`，`supervisor.log` 可能没有内容。看 `logs\whale-bot.log` 就行。

### 9.11 它偶尔回两遍一样的话

发件箱在“动作超时但对方可能已收到”时会重试，宁可重复一句也不丢一句。这是已知取舍，网络抖的时候偶尔出现，不是每轮都这样。频繁出现的话，检查 NapCat 和网络。

### 9.12 它自己退出/反复重启

看门人会在 5 秒后重拉，所以短时间反复看到“机器人退出了”说明它在崩溃循环。处理：

1. 看 `whale-bot.log` 最后 50 行，找第一处报错。
2. 在命令行跑 `node bot\whale-bot.mjs`，让报错直接打在屏幕上。
3. 常见原因：`config.json` 坏了、DSH 路径没了、模型接口一直失败、端口被占、Node 版本太旧。
4. 修好后重启；如果还在循环，先停看门人（面板停止/Ctrl+C），别让它一直打日志。

### 9.13 改完人设没变化

1. 改的是 `home\AGENTS.md` 吗？不是 `config.json`。
2. 存成 UTF-8 了吗？
3. 重启机器人了吗？
4. 人设太长、重点被冲淡？先删到 2000 字以内试。
5. 模型本身不听话？换个强一点的模型试试。

### 9.14 DSH 更新后不能跑

DSH 更新可能改 `cli.js` 的路径。重跑 `设置.bat`，让它重新找 exe 和 cli；或者手动改 `config.json` 的 `dsh.exe`/`dsh.cli`。改完重启。

### 9.15 收到的图/文件在哪

- 图/文件：`home\media\`（文件可能在 `home\media\files\`）。
- 图片缓存 7 天后自动清；文件不自动清，自己看着删。
- 只有主人和白名单的人发的媒体才会下载；陌生人的直接丢。
- 单个文件最大 50 MB；文本文件最多读 400 KB / 20,000 字；压缩包不会解，二进制不会执行。

### 9.16 语音/视频/表情包

- 语音、视频默认只看到 `[record]`/`[video]` 占位，不会转写/理解；只有改代码填上 `ffmpeg` 和本地 whisper 的路径，语音才可能转成文字（这版没有配置向导，不建议折腾）。
- 表情包看到 `[表情包]` 标签。
- 语音回复默认关，而且这版没有语音安装向导；想开得改代码并另配 TTS/ffmpeg，不建议一上来折腾。

### 9.17 中文乱码

- 所有文本文件存 UTF-8（无 BOM 也行，DSH 读得懂）。
- 批处理已经 `chcp 65001`；如果你在旧版 cmd 里手跑，先 `chcp 65001`。
- 用记事本“另存为”时选 UTF-8，不要选“ANSI”。

## 10. 安全、隐私和钱

### 10.1 哪些文件含秘密

- `config.json`：QQ 号、NapCat token、模型 key。
- `%USERPROFILE%\.dsh\profiles\echo-kit\cordis.patch.yml`：模型 key（设置向导写的）。
- `home\`：聊天记录、档案、收的图/文件，可能很私密。
- 备份压缩包：上面全部的副本。

不要把这几样发到群里、贴到网上、传公共网盘。key 泄露了，去模型平台**立刻吊销/换新**，再改 `config.json` 和 DSH profile。

### 10.2 它有多大的权限

- 它默认只在 `home` 这个窝里读写（DSH 的 `workspace-write`），能跑命令、改 `home` 里的文件；`config.json` 和 DSH profile 在窝外，默认不在它的**可写**范围，但别假设它绝对读不到，也别把整个包交给不可信的人。
- 人设里写了“花钱、删东西、往外发东西、改系统设置要先问”，但**人设不是安全边界**。别把报税表、密码本、身份证照片放进 `home`；给它一个专用文件夹。
- 群里的陌生人可以通过消息影响模型（提示词注入）。别让它碰钱、别给它系统管理员权限、别把重要账号的自动操作交给它。
- 截屏默认关死，没有配置开关；语音也默认关死。它不会主动开。
- 想要更大的权限，只能你手动在包根放 `permission-mode.txt` 写 `danger-full-access`；这等于把整块磁盘交给它，别长期开着。

### 10.3 群聊的隐私

- 群里没在白名单的人说话，普通内容它不理；但“耳朵”会把提到它名字/挑衅的消息发给模型判断。也就是说，**这些文字会离开你的电脑，发到你填的模型接口**。
- 不想让群友的话进模型，就别开群，或者只把它放在你完全信任的小群。
- 群里别人发的图/文件，非白名单不下载；但文字仍可能进“耳朵”的判断。

### 10.4 钱

- 模型按 token 计费，从你的接口账户扣。日常闲聊可能几毛到几块一天；贵模型、让它长时间干活、频繁读长档案、群里“耳朵”频繁判断，都会更贵。
- `logs\turns.jsonl` 每轮记了 `tokens.in/out/cache/total`，可以拿它复盘哪条贵。
- 面板看不到余额；去模型平台看。
- 群聊、主动搭话、耳朵判断都会产生调用；不想花就关群、用 `reply-only`/`all` 暂停。

### 10.5 这个包自身的联网

- 除了连你填的模型接口、连本机 NapCat，这个包不做额外的联网上报。
- DSH 和 NapCat 是第三方软件，它们各自有没有遥测，看它们自己的文档；这个包管不了。
- 面板只绑 `127.0.0.1`，不要做公网映射。

## 11. 已知限制

- **Windows only**。批处理和路径处理都是按 Windows 写的。
- **电脑必须开着**。睡眠/关机 = 不在线；提醒迟到超过 10 分钟就丢。
- **一个包一个机器人**。同一个目录重复启动会被看门人拦住；两个机器人号要用两个目录、两个 NapCat 实例。
- **不会自己加好友/进群/退群**。
- **群聊名字触发依赖 `bot.names`**；@ 最稳。
- **语音、视频不理解**；图能不能看懂看模型；文件只收不发，文本文件才读正文。
- **只能发图，不能发文件**；一次最多 2 张。
- **回复会拆气泡、偶尔重复**；这是拟人化和发件箱重试的代价。
- **人设会飘**。模型越小越明显；重要的事用档案/备忘落盘，别只靠聊天上下文。
- **主动搭话没有单独的频率滑块**；不想被搭话，用 `pause.json` 的 `reply-only`（只回消息）或 `all`。
- **截屏/语音这版是关死的**，没有配置开关；要开得改代码。
- **DSH 升级可能改 CLI 路径**；升级后重跑设置。
- **面板没有登录**；只适合本机。

## 12. 常用话术

这些不是硬编码命令，是它按人设能听懂的说法；只有“重启你自己”那三句是写死的。

**记东西**

- “记住：我周三晚上七点到九点有课，别那时候找我。”
- “这条记到 C 页：我妈生日是农历八月十六。”
- “把刚才那个地址记到 D 页。”

**回忆**

- “翻一下我上次说的英语计划。”
- “我之前让你记的快递单号是多少？”
- “查一下档案里我最近在忙什么。”

**提醒**

- “明天早上七点半提醒我带身份证。”
- “四十分钟后提醒我关火。”
- “把八点那个提醒取消。”

**改人设/称呼**

- “以后叫我阿明，你叫小蓝。”——它会把名字写进 `config.json` 和 `AGENTS.md`，下一次就认；群里也叫得应（旧名字留作别名）。
- “你说话太长了，以后一次最多两句。”——它会改 `_回复风格.md`。
- “别老用‘呢’，像客服。”——同上。

**重启**

- 私聊，整条消息只发：“重启你自己”。

## 13. 备份、迁移、升级、卸载

### 13.1 备份清单

- `config.json`
- `home\` 整个目录
- `logs\turns.jsonl`（可选）

备份前停机器人；备份后确认压缩包能打开、文件数对。里面有 key 和聊天记录，别随便放公共网盘。

### 13.2 迁移

见 5.7。核心：新电脑先装三样外部件，再复制包和 `home`，跑设置，重新登录 NapCat。

### 13.3 升级

见 5.8。核心：新目录解压，旧 `home`/`config.json` 搬过去，跑设置刷新 profile。

### 13.4 卸载

1. 面板停止，或黑窗口 `Ctrl+C`。
2. 删除整个包目录。
3. 删除 `%USERPROFILE%\.dsh\profiles\echo-kit\`（DSH profile，里面有 key）。
4. NapCat 里退出机器人号，删除相关配置；不需要就卸载 NapCat。
5. 去模型平台吊销/删除这把 key（如果你不再用）。
6. 如果你建过开机启动快捷方式，删掉。
7. 备份/聊天记录自己决定留不留；删之前想清楚。

卸载不会自动删 QQ 号、不会自动退群；这些要在 QQ/NapCat 里手动处理。
