# 深海灯志 · 最小版

版本 0.3.1 · 2026-10-22

给你的 AI 一套能落地的本地记忆：**一个文件夹、几个文本文件、三百来行代码**。
不装数据库，不起服务，不占显卡，零依赖。

只管记忆这一层——人设、聊天前端、界面都不在这里。

## 六个件

| 件 | 干什么 | 在代码里 |
|---|---|---|
| 存 | 一个主题一个 `.md` 文件，纯文本，能直接打开改 | `memory/` |
| 切 | 按空行切成段，一段只讲一件事 | `splitParagraphs()` |
| 取 | 中文二字切词，建词到段落的索引，算出最相关的三段；查询时按同义词表扩展 | `tokenize()` / `rank()` / `SYNONYMS` |
| 拼 | 三段连出处拼成一块，硬上限 800 字 | `assemble()` |
| 写 | 带日期追加到对应主题；要不要记由提示词判断，答完固定跑一次 | `add()` + `prompt-template.md` |
| 忘 | 90 天没新内容的主题标「搁着」，不再带出来，但文件还在 | `forget()` |

## 0.3 补的两处

0.2 有两个明摆着的坑，这一版各补一半，剩下一半诚实写着：

1. **换个说法就查不到。** 中文二字切词只认字面，「余额」和「还剩多少」一个词都对不上。
   现在 `mem.mjs` 里带一张手写的同义词表（`SYNONYMS`，29 组），查询命中组里任一个说法，就把整组接上一起查，
   分数打 0.6 折，免得同义词盖过原词。停用词也补了一批疑问虚词（「什么」「怎么」「多少」「这个」……），
   问句里那些每回都出现的词不再把不相关的段落拉上来。
   实测（临时造的三段测试本）：问「余额」能翻到写着「还剩多少」的段落，反过来也行；问「困了」能翻到「熬夜」，问「好烦」能翻到「压力」；问「量子力学」这种库里没有的空手。
   但这仍是人工表，不是语义模型——超出表外的说法照样抓瞎，那要上 embedding，得模型和显存。
2. **没人自动记。** 代码不会自己判断哪句话值得记，`add` 只有被调用才写。
   0.3 把这件事写成提示词里的固定收尾：每轮答完必须过一遍「这条会不会改变以后的做法」，
   有就按格式输出 `<记 主题="…">…</>`，机器再把这一行喂给 `add`。
   它靠模型守规矩，不是代码保证；`prompt-template.md` 里那三段就是给这一步用的。

## 三步跑起来

需要 Node 18 以上，没有任何依赖要装。

```bash
node mem.mjs build                     # 建索引
node mem.mjs query "每天学多久"         # 取最相关的几段，拼成上下文块
node mem.mjs add 学习 "2026-10-23 每天二十分钟，从第二章开始。"
```

`query` 实际跑出来是这样（`memory/` 里自带的两个示例文件）：

```
【本子里翻到的，只当参考，不是全部事实】

[1] 学习.md 第 2 段（改于 2026-10-22）
2026-10-19 不喜欢别人替我排日程，每天学多久我自己定，不排表、不定奖惩。

[2] 学习.md 第 1 段（改于 2026-10-22）
2026-10-18 打算用三个月读完《深度工作》，每天二十分钟，从第二章开始。
```

命中几段给几段，最多三段，凑不出 800 字就少给；一个字都对不上就空手，让模型老实答「没查到」。
`memory/` 里的两个文件照它们的样子写，删掉也行。

## 查询怎么写才准（都是实跑出来的，不吹）

这套检索是字面＋同义词表，不是语义模型。手上有两个现成的坑，写文档的时候一起交出去：

1. **短查询最吃字面。** 两三个字好使，因为切完词就是它本身；但一旦是比喻或者换个说法，全看同义词表里有没有。
   实测：问「考不上怎么办」，切出来是「考不 / 不上 / 上怎 / 么办」——中文二字切词把「考不上」切歪了，
   本子里就算写着「怕挂科」也对不上，老老实实空手。同义词表里有「余额↔还剩多少」「困了↔熬夜」这种，才接得上。
   所以：**查不到先换词再试一次，别急着说本子里没有；但也别指望它认意思。**
2. **长查询会把弱相关的段一起拉上来。** 一句话问得越长，命中的词越多，分数低的段也挤进前三。
   实测：把「每天学多久比较好呢，我最近状态不太行，总是想拖到明天，可是又怕时间不够」整句丢进去，
   学习那两段之外，还多拉了一段「作息随机，别按钟点找我」——不算错，但它占掉了 800 字窗口里的一段。
   所以：**查询写短、写具体**，三到八个字、名词为主，比整句问效果好。

空手是**正确行为**：说明本子里确实没有，让模型答「没查到」，好过硬编一段。

## 命令

```
node mem.mjs build            重建索引
node mem.mjs query "问题"      取最相关的几段（自动跳过「搁着」的）
node mem.mjs add 主题 "内容"   追加一条带日期的记忆
node mem.mjs forget           把 90 天没新内容的主题标成「搁着」
node mem.mjs list             看所有主题、段数、多久没改
node mem.mjs synonyms         看同义词表，想加词就改源码里那张表
node mem.mjs selfcheck        体检：多少主题多少段、哪些太久没记、索引过没过期
```

索引缓存在 `.cache/index.json`，文件改动过就自动重建，不用手动管。

`selfcheck` 不打模型、不联网、只读文件，随时能跑；超过 14 天没添新内容的主题会被点出来，
提醒「这套的记忆是靠人往里写才活的」——不写，它就是个空本子。想在别的日子算久，改源码里的 `SELFCHECK_DAYS`。

## 格式就三条

1. **一个主题一个文件**，文件名就是主题名（`学习.md`、`偏好.md`）。
2. **一段一件事**，段与段之间空一行。三百到八百字一段，太碎拼不出意思，太粗占满窗口。
3. **带日期**，下次核的时候对得上。

## 提示词

代码管落盘，判断记不记靠提示词，两份模板在 `prompt-template.md`：
一份说拼好的块怎么摆在问题前面，一份说答完之后怎么判断、按什么格式输出 `<记 主题="…">…</>`。

## 这套的天花板（先知道，免得做完失望）

- **换个说法就找不到（补了一半）。** 常见说法靠 29 组同义词接上了，表外还是抓瞎；「我怕考不上」和「担心」这种得靠语义检索，那要模型和显存。
- **不会自动判断哪条重要（补了一半）。** 写不写靠提示词里那道固定自检出题，模型不守规矩就还是不记；代码不替它判断。
- **不会跨主题联想。** 「最近压力大」和「下周考试」分在两个文件里，它就联不起来。

它存在的意义不是打赢成熟框架，是让你每一步都看得懂、出了问题能定位、想改随时改。
